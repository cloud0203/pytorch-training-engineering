# 验收清单

按用户授权选择层级，不以“完整验收”为由启动未授权训练。只检查实际实现的功能；未验证项记录原因。没有 GPU 时不把 CPU 测试描述成 CUDA/DDP 通过。

## A：文档与静态检查

适用于只允许文档或不允许启动训练的任务。文档任务仅校验所创建的文档和配置示例；代码任务可增加不执行训练的解析、导入及配置检查。

- 目录职责清晰，data 代码与原始数据分开；logs/weight 的 run_id 对应。
- 实际配置字段都被实现或明确拒绝；默认值、路径基准、覆盖优先级一致。
- 输入输出、mask、损失空间、指标分母、batch/step/时间单位写清楚。
- 实验固定更新预算还是数据量预算明确；每卡 batch、数据并行大小、累积次数、尾部政策和名义有效 batch 一致。schema 2 模板不混入旧 epoch 调度字段。
- 声明的设备/精度/调度器与目标版本相符；没有装饰性开关或未实现分支。
- 入口导入无训练、数据写入等副作用；shell 示例不后台启动、不硬编码本机路径。
- 可读格式符合项目规范；Python 独立语句分行，不用分号压缩复杂逻辑。
- 文件链接、YAML/JSON 可解析；没有未完成的 scaffold 占位符。
- 报告区分静态确认、实际运行通过与未验证。

## B：无需训练的逻辑检查

代码实现任务按风险运行，文档任务不需要制造这些测试。

- 指标：已知小数组与手工/可靠实现一致；不等大小分块合并与整批一致，涵盖空 mask、零目标和常量目标。
- sampler：验证划分无重复无遗漏，包含样本数小于 world_size 的情况。
- scheduler：初值、warmup 边界、终点、保存恢复及延长周期政策正确。
- 预算：用实际 loader 长度核对尝试更新数，涵盖尾部不足累积窗口；10,000 成功更新应恰好在第 10,000 次结束，不凑整 epoch。
- 事件：计数跨阈值触发，AMP 跳步不重复触发相同 step 的验证/保存，恢复后不重放已完成事件，最终验证去重。数据量越过预算记录实际超额量。
- checkpoint：原子写入后可读，模拟保存失败不损坏此前文件，配置冲突得到明确错误。
- 配置：未知键、负数、冲突的 resume/init-from、无效 monitor 被拒绝；num_workers=0 合法。

## C：有界训练验证

仅当授权包含小数据试跑时执行。优先使用临时输出目录；写明样本数、最大 batch 数/epoch、设备及超时。

| 检查 | 观察到的通过标准 |
| --- | --- |
| 合成数据闭环 | 实际模型接口完成 forward/backward、验证、保存、重新加载，状态有限 |
| 真实小样本 | 数据 shape/dtype/单位/mask 与模型契约吻合 |
| 极小数据拟合 | 任务适用时损失明显下降，用于排查标签、梯度和归一化问题 |
| epoch 恢复 | 固定环境和数据，连续训练与中断恢复的 LR、step、模型/优化器状态在声明容差内一致 |
| step 恢复 | 非 epoch 末尾且已提交窗口的恢复点，续训样本顺序、数据量计数、LR、事件阈值和模型状态与连续训练一致；未实现不得标为完整续训 |
| init-from | 权重匹配来源，其他训练状态从新阶段开始 |
| 梯度累积 | 简单无随机模型上与等价大 batch 更新一致，覆盖最后不足窗口及不同有效计数 |
| AMP | 有限更新，裁剪顺序正确；跳过更新时 step/scheduler/EMA 行为符合契约 |
| best 选择 | 用可控验证指标序列验证 min/max 选择，不仅检查文件存在 |
| 日志恢复 | epoch 与 step 各自连续，无重复尾部、错误 purge 或旧 best 摘要 |
| batch 对比 | 固定有效 batch 与更新预算时，简单无批依赖模型的更新及处理量吻合；改变有效 batch 时报告数据量变化，不只比较相同 epoch 的 best |

## D：多卡与专项能力

需要相应硬件和授权；未启用的扩展不检查。

- 固定 checkpoint 做单卡/DDP 验证，样本数一致，指标在合理数值容差内一致。
- 包含不能整除 world_size 及某 rank 零验证样本的情况，确保正常退出。
- DDP 训练只验证合理的更新和恢复，不要求不同 world_size 的训练轨迹逐位一致。
- EMA/early stopping 的状态恢复正确，所有 rank 决策一致。
- 已知边界模拟失败时作业有限时间内退出，不留下等待进程或覆盖有效 checkpoint。
- profiler/compile/FSDP 等单独说明验证组合，不由普通 DDP 通过推断其可用。
